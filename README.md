# Rock Paper Scissors Game 🎮✊✋✌️

A fun and interactive Rock Paper Scissors game built using **HTML**, **CSS**, and **JavaScript**. The player competes against the computer, and the game keeps track of scores for each round.

---

## 🔹 Features

- Simple and clean UI
- Interactive gameplay
- Random computer moves
- Scoreboard to track wins/losses
- Dynamic result messages with colors

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

---

## 🧩 How to Play

1. Click on either **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly choose its move.
3. The winner of the round is displayed with a message.
4. Scores are updated after every round.
